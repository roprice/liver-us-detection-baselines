# Liver ultrasound detection baselines

Resource-efficiency baselines for malignant liver-mass detection on
B-mode ultrasound using nnU-Net.

This study trains PlainConvUNet 2D on the [Annotated Ultrasound Liver
(AUL) dataset](https://doi.org/10.5281/zenodo.7272660) and establishes various detection baselines across epoch budgets and training-set sizes. 

The STUDY_LOG.md file introduced on September 21st 2026, documents progress.
